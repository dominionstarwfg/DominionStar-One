Founder Setup

DominionStar v3.1 Founder Edition

Complete these steps before inviting your first 20 agents.

1. Run the database setup

Open Supabase → SQL Editor → New Query. Paste the full contents of SUPABASE-SETUP-v3.1.sql, then click Run.

2. Add your project keys

Open Supabase → Project Settings → API. Copy the Project URL and public anon key into assets/js/supabase-config.js.

3. Configure Auth URLs

Set the Site URL to https://dominionstarld.com and add member-login and member-dashboard redirect URLs.

4. Deploy to Netlify

Deploy the entire DominionStar-Platform-v3.1-Founder-Edition folder.

5. Test one account

Create your own test member account before inviting anyone else.

6. Approve beta members

During this release, approvals are made directly in Supabase Table Editor by changing verification_status from pending to approved and setting founding_member to true for your initial 20 agents.
